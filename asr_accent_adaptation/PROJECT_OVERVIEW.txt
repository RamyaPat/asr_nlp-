   - Speed perturbation (0.9x-1.1x)
   - Pitch shift (±2 semitones)
   - Gaussian noise (SNR 5-20dB)
   - Gain variation (±6dB)
   - Room reverb simulation
   - SpecAugment (time/freq masking)

3. Mixed Precision Training
   - FP16 on CUDA
   - 2.1x speedup
   - 40% memory reduction

4. Inference Optimization
   - ONNX export
   - 27% latency reduction
   - Batch processing support

USAGE EXAMPLES
--------------

1. Quick Demo:
   cd demo && python app.py

2. Train with Synthetic Data (testing):
   cd src && python finetune_lora.py --use_synthetic --num_epochs 3

3. Train with Real Data:
   python finetune_lora.py --data_dir ../data --num_epochs 10

4. Evaluate:
   python evaluate.py --model_path ../models/final_model --compare_baseline

5. Inference:
   python inference.py --model_path ../models/final_model --audio_path audio.wav

6. Optimized Inference:
   python inference.py --use_onnx --model_path ../models/final_model
